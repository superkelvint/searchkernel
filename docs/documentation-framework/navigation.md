# Navigation

The documentation website should lead primarily by **reader intent**.

## Primary front doors

The documentation home page should make these four journeys prominent:

```text
Instant Search
Build a high-quality search experience quickly.

Build with SearchKernel
Use and understand the full Search Kernel product surface.

Operate SearchKernel
Deploy and run Search Kernel reliably.

Contribute to SearchKernel
Develop and extend Search Kernel itself.
```

These are curated entry points into one documentation corpus, not four isolated sites.

## Audience landing pages

Each audience should have a landing page that:

1. states who the section is for;
2. gives the shortest appropriate starting path;
3. surfaces common tasks;
4. links to the most important concepts and reference;
5. points naturally to the next deeper audience journey where appropriate.

For example:

```text
Instant Search
    ↓
successful default experience
    ↓
Build with SearchKernel for deeper control
```

## Diátaxis beneath the front door

Within an audience, navigation follows the relevant Diátaxis modes.

The labels may be audience-appropriate:

```text
Instant Search
    Get started
    Guides
    Concepts
    Reference

Operate SearchKernel
    First deployment
    Operational guides
    Operational model
    Configuration reference

Contribute
    Start contributing
    Development guides
    Architecture
    Developer reference
```

The framework does not require every audience to expose identical labels.

## Canonical pages may serve multiple journeys

Audience landing pages are navigation views over canonical content.

A canonical page may be relevant to multiple audiences. For example, a persistence concept may be linked from Build, Operate, and Contribute.

Do not duplicate the page into three trees.

## Search and deep links

Documentation search, external links, and direct URLs may bypass audience landing pages entirely.

A page should therefore make its own purpose and audience clear enough to stand alone.

Audience paths are strong front doors, not restrictions on navigation.
