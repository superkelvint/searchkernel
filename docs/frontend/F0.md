# F0 — Frontend foundation

## Definition

Vite/React/TypeScript foundation, routing, query state, generated client bootstrap, shell, capabilities, and error boundary.

## Acceptance boundary

The frozen verifier for F0 must exercise the real frontend path required by its manifest. Portable operations use the generated TypeScript client; unsupported capabilities are gated rather than emulated. Any absent future dependency is reported as NOT_APPLICABLE, while an unimplemented verifier remains NOT_IMPLEMENTED and blocks acceptance.

Completion is decided only by:

    frontend-accept F0
