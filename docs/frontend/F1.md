# F1 — Dashboard development backend

## Definition

Development serving and daemon integration for dashboard assets and HTTP access.

## Acceptance boundary

The frozen verifier for F1 must exercise the real frontend path required by its manifest. Portable operations use the generated TypeScript client; unsupported capabilities are gated rather than emulated. Any absent future dependency is reported as NOT_APPLICABLE, while an unimplemented verifier remains NOT_IMPLEMENTED and blocks acceptance.

Completion is decided only by:

    frontend-accept F1
