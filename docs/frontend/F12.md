# F12 — Product hardening

## Definition

Accessibility, keyboard interactions, large payload handling, visual regression, responsiveness, and exports.

## Acceptance boundary

The frozen verifier for F12 must exercise the real frontend path required by its manifest. Portable operations use the generated TypeScript client; unsupported capabilities are gated rather than emulated. Any absent future dependency is reported as NOT_APPLICABLE, while an unimplemented verifier remains NOT_IMPLEMENTED and blocks acceptance.

Completion is decided only by:

    frontend-accept F12
