# F3 — Documents

## Definition

Document browsing, filtering, inspection, and supported write/delete flows through the portable client.

## Acceptance boundary

The frozen verifier for F3 must exercise the real frontend path required by its manifest. Portable operations use the generated TypeScript client; unsupported capabilities are gated rather than emulated. Any absent future dependency is reported as NOT_APPLICABLE, while an unimplemented verifier remains NOT_IMPLEMENTED and blocks acceptance.

Completion is decided only by:

    frontend-accept F3
