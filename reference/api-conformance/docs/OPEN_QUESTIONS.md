# Explicitly not frozen by v0.4

These are intentionally outside the v0.4 constitutional surface rather than accidentally omitted:

- multi-search / federated search API;
- `get_many`;
- delete-by-filter / patch-by-filter;
- clear/truncate index;
- datetime, geo, vector and hybrid retrieval;
- cursor pagination;
- schema evolution/migrations;
- exact native realization of the frozen analyzer contracts;
- filesystem/path portability for lifecycle packaging.
